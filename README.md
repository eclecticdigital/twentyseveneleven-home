# Twenty Seven Eleven — home page concept

A redesigned home page for [twentyseveneleven.in](https://twentyseveneleven.in),
built by Eclectic Digital as a design concept.

**Live preview:** https://eclecticdigital.github.io/twentyseveneleven-home/

- Full-bleed campaign video hero with a transparent header that inverts to a
  solid bar on scroll.
- Instrument Sans (the brand's current typeface) with Bodoni Moda for display.
- All photography, product names and prices are the brand's own, taken from the
  live store for the purposes of this concept.

Static site — `index.html` plus `assets/`. No build step.
